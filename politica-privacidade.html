📋 Política de Privacidade

Última atualização: Novembro de 2025

Caroline Marques Brito - CRP 14/09165-4 está comprometida com a proteção dos seus dados pessoais e com a sua privacidade, em conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018).

1. Quais dados coletamos?

Para realizar o agendamento de consultas, coletamos os seguintes dados:

  • Dados pessoais: Nome completo, CPF, data de nascimento
  • Dados de contato: E-mail, telefone
  • Dados de endereço: CEP, rua, número, bairro, cidade, estado
  • Dados de agendamento: Data e horário das consultas
  • Dados de pagamento: Informações de pagamento processadas pelo Mercado Pago

2. Para que usamos seus dados?

Seus dados são utilizados exclusivamente para:

  • Realizar e confirmar agendamentos de consultas
  • Enviar lembretes e confirmações de consulta
  • Processar pagamentos
  • Manter histórico de atendimento (prontuário)
  • Cumprir obrigações legais e éticas da profissão

3. Com quem compartilhamos seus dados?

Seus dados NÃO são vendidos ou compartilhados com terceiros, exceto:

  • Mercado Pago: Para processar pagamentos (eles têm própria política de privacidade)
  • Provedores de hospedagem: Para armazenar os dados com segurança
  • Quando exigido por lei: Em casos de ordem judicial

4. Por quanto tempo guardamos seus dados?

  • Prontuários e dados clínicos: 5 anos (conforme Resolução CFP nº 001/2009)
  • Dados de agendamento e pagamento: 5 anos (para fins legais e fiscais)
  • Após esse período: Os dados são anonimizados ou excluídos

5. Como protegemos seus dados?

  • ✅ Conexão segura (HTTPS/SSL)
  • ✅ Banco de dados criptografado
  • ✅ Acesso restrito apenas aos profissionais autorizados
  • ✅ Backup regular dos dados

6. Seus Direitos (LGPD)

Você tem direito a:

  • Confirmação: Saber se tratamos seus dados
  • Acesso: Solicitar cópia dos seus dados
  • Correção: Corrigir dados incompletos ou desatualizados
  • Anonimização/Bloqueio: Solicitar bloqueio dos dados
  • Exclusão: Solicitar exclusão dos dados (exceto prontuários obrigatórios)
  • Portabilidade: Receber seus dados em formato estruturado
  • Revogação: Revogar consentimento a qualquer momento
